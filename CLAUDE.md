# Project Guide

## Stack

- Node.js LTS
- JavaScript
- npm

## Conventions

- Use clear, descriptive names for files, functions, and variables.
- Keep modules focused and avoid unrelated refactors.
- Prefer small, testable changes.
- Run the relevant checks before committing.
- Use Conventional Commits for commit messages: `type(scope): description`.

## Git Workflow

Make each commit represent one coherent change. Pull requests should explain
the user-facing result and include validation steps.
